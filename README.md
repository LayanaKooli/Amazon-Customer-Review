# Amazon-Customer-Review - NLP Classification Project

This project applies **Natural Language Processing (NLP)** and **Machine Learning** techniques to analyze Amazon customer reviews. 
The primary objective is to preprocess textual review data, extract meaningful features using techniques such as **TF-IDF**, and **Word2Vec**, 
and build classification models capable of understanding customer feedback. The project follows a complete NLP pipeline, 
including data exploration, text preprocessing, model training, hyperparameter tuning, and performance evaluation, 
providing a comprehensive demonstration of text classification on real-world customer review data.
